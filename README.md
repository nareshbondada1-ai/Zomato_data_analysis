# Zomato Data Analysis

## Project Overview
This project analyzes Zomato restaurant data using Python. The goal is to explore the dataset and discover useful insights through data visualization.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Importing libraries
2. Loading the dataset
3. Exploring the data
4. Data cleaning
5. Data analysis
6. Data visualization
7. Finding insights

## Visualizations
The project contains different visualizations to understand patterns and trends in the Zomato dataset.

## How to Run
1. Clone the repository
2. Install the required libraries
3. Open the Jupyter Notebook
4. Run the cells
